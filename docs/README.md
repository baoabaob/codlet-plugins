# Documentation

This repository owns ordinary official plugin UX and the complete functional acceptance consumer. Core owns Codex implementation, client profiles, Native probes and public SDK declarations.

| Document | Responsibility |
| --- | --- |
| [GUI](spec/gui.md) | Management behavior and UI lifecycle |
| [Marketplace](spec/marketplace.md) | Discovery, metadata, package review and preview tools |
| [Development](development.md) | Clean builds, tests, SDK snapshots and previews |
| [Publishing](publishing.md) | Generated GUI repository, ownership checks and release rules |
| [Known issues](known-issues.md) | Current plugin limitations and acceptance boundaries |
| [Functional consumer](../tests/fixtures/runtime-compatibility/README.md) | Explicit fixture effects and owned Native acceptance |

Use the [Core SDK](https://github.com/baoabaob/codlet/blob/main/docs/spec/codex.md), [Workspace contract](https://github.com/baoabaob/codlet/blob/main/docs/spec/workspace.md), and [Core documentation index](https://github.com/baoabaob/codlet/blob/main/docs/README.md) for runtime contracts.

The [repository map](https://github.com/baoabaob/codlet/blob/main/docs/repository-layout.md) explains ownership. Former Adapter specifications and dated evidence are preserved in [Core's archive](https://github.com/baoabaob/codlet/blob/main/docs/history/adapters/README.md), not maintained as another current API here. `plugins.json` now lists only the GUI.
